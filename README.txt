HARDERSTYLEZZ RADIO - WEBSITE

PREVIEW
1. Unzip the downloaded package.
2. Open the HarderstyleZZ_Radio folder.
3. Double-click index.html to view the website in your browser.
4. Keep your internet connection active for Spotify, YouTube and Google Fonts.

PUBLISH
Upload index.html, style.css, script.js and favicon.svg together to your hosting provider's website/public folder. No database or server programming is required.

UPDATES
Tell ChatGPT what you want to change and ask for updated website files. You do not need to edit code yourself.

INCLUDED
- English-language one-page website
- Premium navy/gold branding, decorative CSS radio artwork
- Spotify and YouTube playlist embeds
- Three official Spotify album embeds
- Coming Soon section
- YouTube, Official Releases, Instagram, TikTok and contact links
- Mobile-responsive navigation

IMPORTANT
This is a music hub, not yet a live 24/7 radio stream. A live player can be integrated later when an AzuraCast stream URL is available.
Spotify and YouTube control the embedded players and may require cookies or login depending on browser and region.
