HARDERSTYLEZZ RADIO — RESPONSIVE WEBSITE V2

Files: index.html, style.css, script.js, favicon.svg, hero-city.jpg.

Publish to GitHub Pages:
1. Unzip this package on your PC.
2. Open https://github.com/harderstylezz/harderstylezz-radio
3. Use Add file > Upload files.
4. Select all five files from the extracted folder (not the ZIP or folder itself).
5. GitHub will replace files with matching names when you commit changes. Confirm the commit.
6. IMPORTANT: delete the old hero-artwork.jpg only if you want to clean up the repository; the new site does not use it.
7. Wait a few minutes, then reload https://harderstylezz.github.io/harderstylezz-radio/ (Ctrl+F5 if necessary).

The website is in English and supports desktop, tablet and mobile.
It uses a real scenic hero image (hero-city.jpg) and live Spotify/YouTube embeds.
The site does NOT claim to have a working 24/7 radio stream: that needs a separate AzuraCast stream URL.
The featured Spotify album artwork and release details come directly from Spotify.
To request changes later, tell ChatGPT what to adjust and ask for updated website files.
