PREVIEW
Unzip the package and double-click index.html. The entire site is static.

PUBLISH TO YOUR EXISTING GITHUB PAGES SITE
Repository: https://github.com/harderstylezz/harderstylezz-radio
Existing Pages address: https://harderstylezz.github.io/harderstylezz-radio/

1. Sign in to GitHub and open the repository above.
2. Select Add file > Upload files (or use the repository file browser upload).
3. Open the extracted HarderstyleZZ_Music_Hub_Publicatieklaar folder.
4. Upload index.html, styles.css, script.js, site-data.js and the WHOLE assets folder.
   Important: files must be at the repository ROOT, not inside a new subfolder.
   If the browser cannot upload a folder, upload its image files to an assets folder
   created in the repository. Preserve filenames exactly.
5. Choose Commit changes. Wait for the GitHub Pages deployment to finish.
6. Refresh the Pages address above, preferably with Ctrl+F5.
7. Check every cover and link on desktop and mobile.

If Pages is not yet enabled, choose Settings > Pages > Deploy from a branch,
select main and /(root), then Save. Do not change an already working Pages setting.

IMPORTANT
This ZIP does NOT automatically publish to GitHub or register harderstylezz.com.
The Silent Realm does not yet have a confirmed direct Spotify link. Its countdown
switches to OUT NOW on release day; a Listen Now button is displayed only when
its direct link is supplied later.
